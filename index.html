Sobre Mí

¡Hola! Soy Santiago, desarrollador full stack con experiencia diseñando e implementando sistemas completos: desde arquitecturas de autenticación y control de acceso, hasta módulos de gestión financiera y migraciones de stack en producción. Trabajo tanto en backend (Java, Spring Boot, bases de datos relacionales) como en frontend (Vue, React, JavaScript), combinando solidez técnica con atención al diseño visual.

Me apasiona resolver problemas reales con código limpio y escalable, sin perder de vista la experiencia del usuario. Si buscas un desarrollador que entienda tanto la lógica detrás de un sistema como el impacto visual de una interfaz, ¡hablemos de tu próximo proyecto!

API NASA

Descripción:

Proyecto educativo de front-end desarrollado en colaboración, que consume la API APOD (Astronomy Picture of the Day) de la NASA. A través de un calendario interactivo, el usuario puede seleccionar un día y visualizar la fotografía astronómica publicada por la NASA en esa fecha, junto con su título y explicación.

Funcionalidades:

  • Calendario interactivo para seleccionar un día específico
  • Consumo de la API APOD de la NASA (imagen, título y descripción)
  • Búsqueda por fecha personalizada mediante selector de fecha
  • Botón para ver la imagen astronómica del día actual
  • Manejo del caso en que la publicación del día es un video en vez de imagen
  • Guardado local de imágenes favoritas (Local Storage)

Tecnologías:

  • HTML5 / CSS3 / JavaScript
  • Bootstrap
  • Fetch API (consumo de API REST)
  • NASA Open API (APOD)
